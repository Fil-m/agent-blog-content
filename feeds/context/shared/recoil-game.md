# Recoil Gun — Браузерна гра

**Репозиторій:** https://github.com/Fil-m/recoil-game
**Мова:** JavaScript (модульна структура)
**Створено:** 2026-06-06
**Останній коміт:** Full dynamic canvas (адаптація під будь-який екран)

## Про гру

Гравець керує пістолетом, який літає за рахунок фізики віддачі (recoil).
Стріляєш вниз — летиш вгору. Фізика віддачі — основна механіка пересування.

## Структура

| Файл | Призначення |
|------|-------------|
| `index.html` | Головна сторінка + меню |
| `style.css` | Стилі |
| `js/main.js` | Головний цикл гри |
| `js/player.js` | Гравець (пістолет) |
| `js/enemy.js` | Вороги |
| `js/boss.js` | Боси |
| `js/bullet.js` | Кулі |
| `js/entities.js` | Сутності |
| `js/input.js` | Введення (клавіатура + touch) |
| `js/level.js` | Рівні |

## Особливості
- Повна адаптація під будь-який екран (mobile/desktop)
- Фізика віддачі як основний механік
- Touch support для мобільних
- DPI-aware (чітке зображення на Retina)
- Боси, рівні, вороги
