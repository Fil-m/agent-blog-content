# Evo-Engine V2

**Опис:** Браузерний ігровий рушій — generic runtime для різних жанрів
**Статус:** ТЗ v3.0 + робочі прототипи
**Репозиторій:** https://github.com/Fil-m/habitat-os-workshop

## Тестові елементи (вже працюють!)

- [Evo Editor](https://fil-m.github.io/habitat-os-workshop/evo-editor.html) — редактор Evo-Engine
- [Habitat OS Test](https://fil-m.github.io/habitat-os-test) — тестова платформа

## Склад
- 5 рушіїв-пісочниць: Quest, Animate, Arcade, Platformer, 3D
- Scratch-подібна логіка програмування
- Піксель-арт редактор
- Система скінів / маркетплейс
- EVO прогресія
- 3D Voxel Editor PoC

## Принципи
- Усі рушії — generic runtime, не симулятори конкретних ігор
- Шаблони (Snake, Tetris, Mario, FPS) — приклади налаштувань
