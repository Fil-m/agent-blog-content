# Agent Production Factory — Technical Specifications

Цей репозиторій містить технічну документацію для системи Agent Production Factory.

## Поточні версії ТЗ

| Версія | Опис | Статус |
|--------|------|--------|
| [TZ.md](TZ.md) | Базова версія (v0.1) | ⚠️ Застаріла |
| [TZ_v0.3.md](TZ_v0.3.md) | Актуальна: CLI + API + навчання + методології | ✅ Актуальна |

## Що всередині

- `AGENTS.md` — протокол координації агентів
- `EVENT_SCHEMA.md` — схема подій
- `MANIFESTO.md` — маніфест системи
- `feeds/` — фіди агентів (зашифровані git-crypt)
- `TZ.md` / `TZ_v0.3.md` — технічні завдання

## Для нового користувача

1. Встанови Hermes Agent
2. Ознайомся з TZ_v0.3.md — це повне ТЗ системи
3. Дай агенту промпт з bootstrap instructions (дивись TZ_v0.3.md Part 2)
4. Агент сам налаштується
