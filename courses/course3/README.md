# Курс 3: Agentic AI on Google Cloud — Google Skills

## Посилання

- **Головна:** https://www.skills.google/paths/3273
- **💰 Безкоштовно, self-paced**
- **⏱ ~42 години загалом, 9 активностей**
- **🏆 Skill badge після завершення**
- **🔄 Останнє оновлення: 2 місяці тому (квітень 2026)**
- **Організатор: Managed by Google Cloud**

## Опис

Цей learning path проводить учнів через принципи, розробку та деплоймент інтелектуальних multi-agent систем. Контент фокусується на використанні ключових Google Cloud технологій, включаючи вступ до Gemini Enterprise, та практичні навички побудови й захисту multi-agent архітектур з використанням Agent Development Kit (ADK).

Після завершення учні зможуть: прискорювати обмін знаннями, інтегруватися з enterprise базами даних, та деплоїти безпечні, advanced AI agent рішення на Google Cloud.

## Модуль 7: Build AI Agents with Enterprise Databases (4 год)

🔗 https://www.skills.google/paths/3273/course_templates/1436

- Vector embeddings для семантичного пошуку
- Structured queries (SQL, GraphQL)
- Audit logging
